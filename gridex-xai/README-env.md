## run_q1_region_selection_inference.sh

This script will call `internal_launchers/launch_q1_region_selection_shards.sh`

`internal_launchers/launch_q1_region_selection_shards.sh` will activate running environment, check python module `flashinfer`, and call `infer_q1_region_selection.py`

`infer_q1_region_selection.py` imports torch, transformers, qwen_vl_utils, vllm
